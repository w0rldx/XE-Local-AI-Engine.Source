# Comparing backup software for a small office

We looked at four backup tools for the office. All of them can back up to a local disk and to an offsite copy; the
differences are in restore speed, encryption and how much they cost per machine.

## Backup and restore features

Tool A restores single files from a web page and can restore a full machine image. Tool B deduplicates backup data
very well but its restore of a full machine is slow. Tool C is free and scriptable but has no image backup. Tool D
bundles offsite backup storage into the licence.

## Encryption

All four encrypt the offsite backup copy. Only tools A and D can store the backup encryption key in escrow with the
vendor, which some offices want and others refuse.

## Price

Prices range from zero for tool C to about eight euros per machine per month for tool D including storage.

## Recommendation

For an office with fewer than ten machines, tool A offered the best balance. The comparison says nothing about how
often restores should be tested; that is an office policy, not a software feature.
