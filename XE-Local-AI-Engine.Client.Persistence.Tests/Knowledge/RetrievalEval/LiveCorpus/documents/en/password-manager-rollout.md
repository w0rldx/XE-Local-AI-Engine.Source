# Password manager rollout

We are moving every team to the shared password manager over three phases.

## Phase one: administrators

Administrators move first and must register two hardware security keys each: one on the keyring and one locked in
the office safe. Accounts that can reset other accounts may not use one-time codes from a phone.

## Phase two: shared vaults

Team vaults replace the spreadsheet of shared logins. Every vault has two owners, so a holiday never blocks access.
Personal items stay in the personal vault and are never visible to administrators.

## Phase three: everyone else

The remaining staff are onboarded in groups of ten during a one-hour session. Each person prints an emergency kit
with the recovery code and keeps it at home, not in the office.

## Offboarding

When someone leaves, their access to team vaults is revoked the same day, and every shared password they could see
is rotated within a week.
