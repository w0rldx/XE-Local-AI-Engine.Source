# scripts/

One line per top-level script and subfolder, taken from each script's header comment. Generated by
`scripts/generate-scripts-readme.py`; do not edit by hand. Each script's header documents its flags and exit codes.
Stopping a dev host safely: [README-dev-stop.md](README-dev-stop.md).

## Scripts

- [`aspire-readiness-smoke.sh`](aspire-readiness-smoke.sh) — Bounded live readiness smoke for this worktree's isolated Aspire AppHost.
- [`assembly-guard.sh`](assembly-guard.sh) — detect a test run whose assemblies were overwritten underneath it.
- [`build-lock-status.sh`](build-lock-status.sh) — who holds the shared build lock, for how long, how far along, and who waits.
- [`capture-agent-framework-dependencies.sh`](capture-agent-framework-dependencies.sh) — Capture exact Release/Debug direct + transitive NuGet graphs and package status reports at two git commits.
- [`dev-aspire-common.sh`](dev-aspire-common.sh) — Shared, side-effect-free helpers for the worktree-scoped Aspire scripts.
- [`dev-start.sh`](dev-start.sh) — Start this checkout/worktree's AppHost in isolated mode.
- [`dev-status.sh`](dev-status.sh) — Show a filtered, token-free view of this worktree's Aspire instance.
- [`dev-stop-select.py`](dev-stop-select.py) — Select processes provably attached to one Aspire AppHost from a /proc snapshot.
- [`dev-stop.sh`](dev-stop.sh) — Stop only the Aspire instance registered for this checkout/worktree's AppHost.
- [`docs-inventory-check.py`](docs-inventory-check.py) — Fail when the docs have fallen behind an inventory the code owns, or agent-knowledge outgrows its caps.
- [`generate-release-notes.sh`](generate-release-notes.sh) — Generate GitHub release notes (markdown) from conventional commits since the previous release tag, for feeding into `vpk pack --releaseNotes`.
- [`generate-scripts-readme.py`](generate-scripts-readme.py) — Regenerate scripts/README.md, the one-line index of every top-level script and subfolder under scripts/.
- [`gpu-smoke-driver.py`](gpu-smoke-driver.py) — HTTP driver for scripts/run-gpu-smoke-local.sh.
- [`lab-api.sh`](lab-api.sh) — one logged call against the lab node that scripts/lab-up.sh prepared.
- [`lab-driver.py`](lab-driver.py) — HTTP driver for scripts/lab-up.sh: brings a lab node's state in line with a profile, one ensure step at a time.
- [`lab-up.sh`](lab-up.sh) — bring this checkout's lab node to a declared state and hand it over before any LLM turn.
- [`lint-release-scripts.sh`](lint-release-scripts.sh) — static analysis for the release-critical shell + PowerShell scripts.
- [`merge-cobertura.py`](merge-cobertura.py) — Merge Cobertura line coverage without double-counting repeated source lines.
- [`model-matrix-driver.py`](model-matrix-driver.py) — Driver for scripts/run-model-matrix-local.sh: pinned models, scenario checks against a running dev host, the verdict.
- [`openapi-live-check.sh`](openapi-live-check.sh) — Compare the committed frontend client with a freshly started desktop backend.
- [`python-validation.sh`](python-validation.sh) — repo Python quality gate (ruff / pyrefly / pytest / bandit)
- [`read-release-version.py`](read-release-version.py) — Read and validate the application version from the canonical release manifest.
- [`regen-after-merge.sh`](regen-after-merge.sh) — regenerate and stage the generated and sorted frontend files after a merge.
- [`run-agent-framework-hardware-compat.sh`](run-agent-framework-hardware-compat.sh) — Opt-in hardware lane: fixed GGUF + real llama-server through the production invocation path.
- [`run-agent-framework-validation.sh`](run-agent-framework-validation.sh) — Fresh, serialized validation for the Agent Framework 1.15 / MEAI closure.
- [`run-backend-tests.sh`](run-backend-tests.sh) — THE local backend gate: one build, then every enrolled test project.
- [`run-docker-smoke-local.sh`](run-docker-smoke-local.sh) — OPT-IN real-daemon smoke for the container runtime and the sandbox.
- [`run-e2e-local.sh`](run-e2e-local.sh) — OPT-IN local runner for the Playwright E2E suite.
- [`run-gpu-smoke-local.sh`](run-gpu-smoke-local.sh) — OPT-IN live GPU smoke for a real, locally started node.
- [`run-model-matrix-local.sh`](run-model-matrix-local.sh) — OPT-IN live model matrix: pinned GGUF models, scenario checks through a real local node.
- [`run-release-contract-tests.sh`](run-release-contract-tests.sh) — Auto-enroll every release/compliance contract test and reject vacuous green runs.
- [`run-retrieval-eval-local.sh`](run-retrieval-eval-local.sh) — OPT-IN real-model retrieval eval (RetrievalEvalLiveTests).
- [`run-tests-memory-safe.sh`](run-tests-memory-safe.sh) — Memory-safe runner for the XE-Local-AI-Engine.Tests module.
- [`run-tool-grammar-smoke-local.sh`](run-tool-grammar-smoke-local.sh) — OPT-IN live tool-grammar smoke against a real llama-server.
- [`skill-lint.py`](skill-lint.py) — Validate a repository-hosted Agent Skill without external dependencies.
- [`squash-guard.sh`](squash-guard.sh) — the checks the coordinator runs on develop immediately before `git merge --squash <branch>`.
- [`test-durations.py`](test-durations.py) — Summarise TRX test durations per class, per test and per namespace.
- [`with-build-lock.sh`](with-build-lock.sh) — run a command holding the repo-wide, cross-process build lock.
