# User guide — provenance

This is the end-user guide for the app: download, install (Windows & Linux), first run, features,
troubleshooting, privacy, and a plain-language glossary. It is meant for anyone using the app, not just
developers.

These pages began life in the separate `XE-Local-AI-Engine.Tester-App` repository, which hosted the
private-beta tester program and its download builds. That repo is being retired; the guide was moved here
(the public, Apache-2.0 source repo) and generalized from "tester hub" framing into a general help guide.

- `README.md`, `docs/*.md` — the guide itself.
- `media/` — screenshots and short clips the guide links to.

App downloads are on this repository's [Releases](https://github.com/w0rldx/XE-Local-AI-Engine.Source/releases/latest) page.
