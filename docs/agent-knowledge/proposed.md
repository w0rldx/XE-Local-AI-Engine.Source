### Embedding profile: chosen by name, part of the vector identity
**Rule:** an embedding model's prompt format and pooling come from `EmbeddingModelProfile.For`, matched on the model segment of the resolved name (after the last `/`, cut at the first `:`), never from GGUF architecture or pooling metadata. The profile's identity tag is part of the stored vector identity, and any change to a profile's prefix or pooling bumps its tag version. **Prevents:** chat Qwen3 and Qwen3-Embedding sharing one profile (one architecture id); the launcher and the knowledge base disagreeing about one shared `(model, Embedding)` process; a format or pooling change mixing old and new vectors under one identity instead of staling only that profile's rows. **Authority:** `EmbeddingModelProfile`, `KnowledgeEmbeddingVectorPolicy`, `EmbeddingModelProfileTests.EveryTag_NamesItsPooling_SoAPoolingChangeCannotKeepItsTag`.

### The lease acquisition enters the runtime-mutation gate privately
**Rule:** inside `LlamaServerRuntimeMutationGate`, `AcquireLeaseOrNullAsync` enters through the private `EnterAsync`, never the public `EnterExclusiveAsync` or `EnterSharedAsync`, because the public entries raise idle-holder demand. Demand is raised once, at the top, and only when `raisesDemand` is true. **Prevents:** a lease taken with `raisesDemand: false` (the Model Lab session's own cold start) still raising demand through the nested public entry and evicting its own session. **Authority:** `LlamaServerRuntimeMutationGate.AcquireLeaseOrNullAsync`, `LlamaServerRuntimeMutationGateTests`.

### A GPU queue peeks before it touches the gate
**Rule:** a polling consumer of `IGpuWorkGate` (benchmark, dataset generation, the training run queue) checks for queued work (`HasQueuedWorkAsync`, `PeekNextKindAsync`) before `TryBeginShared` or `TryBeginExclusive`. A refused gate request is GPU demand. **Prevents:** an empty poll every few seconds evicting an idle warm Model Lab worker over nothing. **Authority:** `BenchmarkQueueHostedService`, `DatasetGenerationHostedService`, `GpuWorkGate.TryBeginShared`.

### Whisper bypasses the GPU work gate and the lease
**Rule:** whisper-server takes only `IGpuModelLoadAdmission`, never `IGpuWorkGate` or the llama runtime-mutation lease, so any GPU-wide policy that lives on those two (idle-holder demand, exclusivity) must be wired into `WhisperServerProcessSupervisor` explicitly. **Prevents:** a new GPU holder or exclusivity rule that every other runtime honours while whisper loads beside it. **Authority:** `WhisperServerProcessSupervisor.AdmitGpuLoadAsync`, `WhisperServerSupervisorTests`.

### A null process read must not mean gone
**Rule:** a probe of `/proc/[pid]/stat` returns a tri-state (`TrainingProcessPresence`: `Alive`, `Gone`, `Unknown`), and only `Gone` (or a verified kill, `TrainingReapOutcome.Verified`) lets a caller delete the last record of a process. Never collapse "no such entry" and "entry unreadable" into one null. **Prevents:** a receipt deleted for a live GPU holder whose stat could not be read, stranding its VRAM with nothing left to find it by. **Authority:** `LinuxTrainingProcessInspector`, `TrainingProcessReaper`, `ModelLabWarmReceipts.ReapAsync`, `LinuxTrainingProcessGroupTests`.

### A Model Lab hook registers onto the job's ExitStack as it is made
**Rule:** in `modellab.py`, a class that installs hooks takes the job's `contextlib.ExitStack` and pushes each handle onto it as it registers it (`stack.enter_context(...)`), and a patch of a shared registry puts its restore on the stack before the swap (`_AttentionRows`: `stack.callback` before `functions["sdpa"] = ...`). **Prevents:** a constructor that fails halfway leaving a hook or the wrapped `sdpa` on a model a warm worker keeps for the next job, which then exits `worker-poisoned`. **Authority:** `_Tracer`, `_AttentionRows`, `_left_behind` in `tools/training/modellab.py`, `test_modellab_serve.py`.

### The training runtime install is detached: admit inside the start transaction
**Rule:** a check that must hold for the whole install or remove (no GPU job runs from the runtime directory) is passed into `ITrainingRuntimeService.InstallAsync` and `RemoveAsync` as the admission delegate, which the provider awaits after it publishes the non-ready phase. A check in the endpoint or the orchestration service before the call is UX only. **Prevents:** a Model Lab start taking its lease between an outer check and the detached install, then running from the directory the install swaps. **Authority:** `TrainingRuntimeService.PublishThenAdmitAsync`, `TrainingRuntimeOrchestrationService.AdmitAsync`, `ModelLabExperimentService` (the phase re-read after the lease), `TrainingRuntimeServiceTests`.

### A cosine threshold cannot tell a paraphrase from a one-word contradiction
**Rule:** never let an embedding-cosine threshold alone delete or merge user knowledge (memory dedup or anything like it). Measured embedders score a lesson and its one-word contradiction ("always" vs "never") as close as two paraphrases, so a threshold that catches duplicates also drops contradictions. Semantic memory dedup stays off by default until a contradiction-aware check sits beside the cosine; re-run the calibration before enabling it for any embedder. **Prevents:** a lesson that reverses a live memory being silently discarded as its duplicate. **Authority:** `MemoryExtractionOptions.SemanticDedupEnabled`, `MemoryDedupCalibrationLiveTests`, `MemoryDedupPairSetTests`.
