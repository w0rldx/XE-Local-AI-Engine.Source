### An in-process MCP test tool honours its token and teardown runs under one deadline
**Rule:** a blocking tool served by `InProcMcpServer` awaits its gate with the call's `CancellationToken`, a test releases that gate in `finally`, and the fixture's whole teardown runs under one deadline, recording an expiry in `McpTeardownLog` instead of throwing it. **Prevents:** a test host hanging the backend gate: `McpServer.DisposeAsync` waits for in-flight handlers, so a gated tool that ignores cancellation, left parked by a failed assertion, blocks disposal forever. **Authority:** `InProcMcpServer.DisposeAsync`, `McpTeardownLog`, `InProcMcpServerSmokeTests.Dispose_WithAnUncancellableToolCallInFlight_CompletesWithinTheBound`.

### Embedding profile: chosen by name, part of the vector identity
**Rule:** an embedding model's prompt format and pooling come from `EmbeddingModelProfile.For`, matched on the model segment of the resolved name (after the last `/`, cut at the first `:`), never from GGUF architecture or pooling metadata. The profile's identity tag is part of the stored vector identity, and any change to a profile's prefix or pooling bumps its tag version. **Prevents:** chat Qwen3 and Qwen3-Embedding sharing one profile (one architecture id); the launcher and the knowledge base disagreeing about one shared `(model, Embedding)` process; a format or pooling change mixing old and new vectors under one identity instead of staling only that profile's rows. **Authority:** `EmbeddingModelProfile`, `KnowledgeEmbeddingVectorPolicy`, `EmbeddingModelProfileTests.EveryTag_NamesItsPooling_SoAPoolingChangeCannotKeepItsTag`.

### The lease acquisition enters the runtime-mutation gate privately
**Rule:** inside `LlamaServerRuntimeMutationGate`, `AcquireLeaseOrNullAsync` enters through the private `EnterAsync`, never the public `EnterExclusiveAsync` or `EnterSharedAsync`, because the public entries raise idle-holder demand. Demand is raised once, at the top, and only when `raisesDemand` is true. **Prevents:** a lease taken with `raisesDemand: false` (the Model Lab session's own cold start) still raising demand through the nested public entry and evicting its own session. **Authority:** `LlamaServerRuntimeMutationGate.AcquireLeaseOrNullAsync`, `LlamaServerRuntimeMutationGateTests`.

### A GPU queue peeks before it touches the gate
**Rule:** a polling consumer of `IGpuWorkGate` (benchmark, dataset generation, the training run queue) checks for queued work (`HasQueuedWorkAsync`, `PeekNextKindAsync`) before `TryBeginShared` or `TryBeginExclusive`. A refused gate request is GPU demand. **Prevents:** an empty poll every few seconds evicting an idle warm Model Lab worker over nothing. **Authority:** `BenchmarkQueueHostedService`, `DatasetGenerationHostedService`, `GpuWorkGate.TryBeginShared`.

### Whisper bypasses the GPU work gate and the lease
**Rule:** whisper-server takes only `IGpuModelLoadAdmission`, never `IGpuWorkGate` or the llama runtime-mutation lease, so any GPU-wide policy that lives on those two (idle-holder demand, exclusivity) must be wired into `WhisperServerProcessSupervisor` explicitly. **Prevents:** a new GPU holder or exclusivity rule that every other runtime honours while whisper loads beside it. **Authority:** `WhisperServerProcessSupervisor.AdmitGpuLoadAsync`, `WhisperServerSupervisorTests`.

### A null process read must not mean gone
**Rule:** a probe of `/proc/[pid]/stat` returns a tri-state (`TrainingProcessPresence`: `Alive`, `Gone`, `Unknown`), and only `Gone` (or a verified kill, `TrainingReapOutcome.Verified`) lets a caller delete the last record of a process. Never collapse "no such entry" and "entry unreadable" into one null. **Prevents:** a receipt deleted for a live GPU holder whose stat could not be read, stranding its VRAM with nothing left to find it by. **Authority:** `LinuxTrainingProcessInspector`, `TrainingProcessReaper`, `ModelLabWarmReceipts.ReapAsync`, `LinuxTrainingProcessGroupTests`.

### A Model Lab hook registers onto the job's ExitStack as it is made
**Rule:** in `modellab.py`, a class that installs hooks takes the job's `contextlib.ExitStack` and pushes each handle onto it as it registers it (`stack.enter_context(...)`), and a patch of a shared registry puts its restore on the stack before the swap (`_AttentionRows`: `stack.callback` before `functions["sdpa"] = ...`). **Prevents:** a constructor that fails halfway leaving a hook or the wrapped `sdpa` on a model a warm worker keeps for the next job, which then exits `worker-poisoned`. **Authority:** `_Tracer`, `_AttentionRows`, `_left_behind` in `tools/training/modellab.py`, `test_modellab_serve.py`.

### The training runtime install is detached: admit inside the start transaction
**Rule:** a check that must hold for the whole install or remove (no GPU job runs from the runtime directory) is passed into `ITrainingRuntimeService.InstallAsync` and `RemoveAsync` as the admission delegate, which the provider awaits after it publishes the non-ready phase. A check in the endpoint or the orchestration service before the call is UX only. **Prevents:** a Model Lab start taking its lease between an outer check and the detached install, then running from the directory the install swaps. **Authority:** `TrainingRuntimeService.PublishThenAdmitAsync`, `TrainingRuntimeOrchestrationService.AdmitAsync`, `ModelLabExperimentService` (the phase re-read after the lease), `TrainingRuntimeServiceTests`.

### A cosine threshold cannot tell a paraphrase from a one-word contradiction
**Rule:** never let an embedding-cosine threshold alone delete or merge user knowledge (memory dedup or anything like it). Measured embedders score a lesson and its one-word contradiction ("always" vs "never") as close as two paraphrases, so a threshold that catches duplicates also drops contradictions. Semantic memory dedup stays off by default until a contradiction-aware check sits beside the cosine; re-run the calibration before enabling it for any embedder. **Prevents:** a lesson that reverses a live memory being silently discarded as its duplicate. **Authority:** `MemoryExtractionOptions.SemanticDedupEnabled`, `MemoryDedupCalibrationLiveTests`, `MemoryDedupPairSetTests`. ### Re-check OLMoE's config defaults on a transformers bump
**Rule:** when the training runtime's transformers pin moves, compare `OlmoeConfig`'s defaults for `sliding_window`, `attention_chunk_size`, `num_kv_shared_layers` and `output_router_logits` with what the host assumes for a key that `config.json` leaves out. The host reads the raw `config.json` (`BaseCheckpointConfigV1`: a missing key is null or false), while `modellab.py` reads the loaded config, where the class default fills a missing key; both refusals must agree. **Prevents:** a preflight that admits attention or a trace the script then refuses after the weights are on the GPU, or a script that admits a config the host would have refused, because a new class default is non-null or true. **Authority:** `ModelLabCheckpointPreflightService.AttentionRefusalOrNull` and its `TraceRefusalMessage`, `modellablib.attention_refusal`, the `output_router_logits` check in `modellab.trace`.

### Re-prove the routing hook on a transformers bump
**Rule:** when the transformers pin moves, re-run the check that the router hook's stash equals what the experts consumed: for every step and block, the ids and bf16 weights `_Routing` stashed from the router's output must be bitwise equal to `top_k_index[-1]` and `top_k_weights[-1]` seen by a wrapper on the experts' own forward, and the tokens and logits must stay bitwise equal with routing on and off. The stubbed CPU tests check the hook's mechanics, not that the router's output is still what the experts receive. **Prevents:** routing labelled as measured while a new transformers version rescales, recasts or re-picks the weights between the router and the experts. **Authority:** `_Routing` and `routers_of` in `tools/training/modellab.py`, `test_modellab_routing.py`.

### Size the application bundle budget for the Windows pack
**Rule:** when raising `applicationJavaScriptBytes` in `XE-Local-AI-Engine.Client.React/config/bundle-budget.json`, leave at least 400 B above the Linux measurement. The Windows `package / build-pack (win-x64)` job measures the main `index` chunk about 335 B larger than the Linux build of the same commit, and only the nightly `dev-build` and `release` run it. **Prevents:** a budget raise that is green on every push (Linux only) failing the nightly Windows pack. **Authority:** `scripts/CheckBundleBudget.mjs`, the `build-pack` job in `.github/workflows/package-velopack.yml`.

### A browser hub socket needs the echo, the mapping callback and UseWebSockets before authentication
**Rule:** every `MapHub` in `Program.MapNodeHubs` passes `ConfigureHubTransport`, the node keeps echoing `xe.bearer`, and `app.UseWebSockets()` stays immediately before `app.UseAuthentication()`. Prove a pipeline-order change on real Kestrel (`HubBearerSubprotocolKestrelTests`), never on TestHost: TestHost installs its own WebSocket feature, so `HubBearerSubprotocolTests` stays green when the order breaks. Keep both SPA hub builders at `LogLevel.Warning`. **Prevents:** every browser socket silently dropping to long polling while the hub reports connected (no echo, a hub mapped without the callback, or `UseWebSockets` after authentication), and a builder at Information printing the socket URL with the token. **Authority:** `NodeJwtBearerEvents.MessageReceived`, `Program.ConfigureHubTransport`, `EndpointAuthorizationPolicyTests.EveryHub_EchoesTheBearerSubprotocolAndNothingElse`, `HubBearerTransport.ts`.
