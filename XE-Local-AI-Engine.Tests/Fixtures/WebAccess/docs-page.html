Configuring retries

The client retries a failed request up to three times by default, waiting longer before each attempt. The wait starts at two hundred milliseconds and doubles on every retry, with a random jitter so that many clients do not retry in step.

Changing the retry count

Set maxRetries on the client options to change how many attempts are made. A value of zero turns retries off entirely, which is what you want for requests that are not safe to repeat.

var client = new WidgetClient(new WidgetOptions { MaxRetries = 5 });

Which errors are retried

Only connection failures and responses with status 502, 503 or 504 are retried. A 4xx response is returned to the caller at once, because repeating a request the server rejected will not change the answer.
