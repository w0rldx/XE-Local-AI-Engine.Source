# Application-layer types that still depend on a node DbContext (operator decision D5).

# Format: <type full name>|<section>|<reason>
# Sections:
#   permanent - composition, migration bootstrap, or a documented maintenance job. It stays.
#   migrate   - a query that belongs behind a *Store in XE-Local-AI-Engine.Client.Persistence. A later
#               sub-slice deletes its group.
#
# Shrink-only in both directions, like CommentBudgetAllowlist.txt and PositionalRecordAllowlist.txt beside it:
# an unlisted holder fails the fence, and a listed type that no longer holds a context fails as stale. Enforced by
# Architecture/ApplicationDbContextFenceTests.cs. Rule: docs/wiki/16-code-conventions.md.
#
# A compiler-generated closure or async state machine is folded onto the type that declares it, so an entry names a
# type a reader can go and edit.
