#
# Format: <type full name>|<section>|<catching symbol and why that is every escape route>
# Sections:
#   service - caught or classified inside XE-Local-AI-Engine.Client.Application; it never reaches the host.
#   host    - caught by the host endpoint(s) or hub that call the throwing service, each with its own status.

# Shrink-only in both directions, like DbContextUserAllowlist.txt beside it: an unlisted unhandled type fails, and a
# listed type a handler now names, or that no longer exists, fails as stale. Enforced by
# Architecture/ExceptionHandlerCoverageTests.cs. A new throw site of a listed type must be caught the same way.
